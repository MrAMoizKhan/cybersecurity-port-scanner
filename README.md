# Cybersecurity Port Scanner

A beginner-friendly Python TCP Port Scanner.

## Features
- TCP port scanning
- Open and closed/filtered port detection
- Basic risk classification
- Automatic security report generation

## Technologies
- Python
- Socket Library
- Ubuntu Linux (WSL)

## How to Run

python scanner.py

Enter your target IP when prompted.

## Disclaimer

Use this tool only on systems you own or have permission to scan.
